# 一方 · 隐藏优势探索

这是一个无需安装依赖的移动端 H5 测试原型，包含测试首页、24 道逐题作答、自动评分、雷达图、分层结果解读和答题进度保存。

直接双击 `index.html` 即可使用。页面不依赖网络，也不会向服务器发送答案。

如果想让同一 Wi-Fi 下的手机查看，可以在这个文件夹运行：

```powershell
node .\preview-server.js
```

然后在手机浏览器访问电脑的局域网地址，例如 `http://192.168.0.107:8000`。电脑需要保持开机，并且预览进程不能关闭。这个预览服务只用于开发和展示；正式分享应部署到静态网站托管平台。

## 文件结构

- `index.html`：三个页面状态与整体语义结构
- `styles.css`：响应式视觉样式
- `questions.js`：8 个维度和 24 道题，单独维护，便于替换
- `app.js`：作答流程、评分、雷达图和结果生成

## 当前题库的设计方式

共有 8 个非诊断性优势维度：洞察力、创造力、共情力、行动力、探索力、表达力、协作力和学习力。

每道题有 4 个生活化选项。选项以主要维度计 2 分，并以一个相关维度计 1 分。24 道题中，每个维度作为主要选项出现 12 次，因此题库分布均衡。

结果百分比不是标准分数，而是把个人得分与该维度在当前题库中的最大可获得分数相比，用来展示相对强弱。结果页刻意使用“线索”和“倾向”，避免把测试包装成诊断或绝对评价。

## 如何更换题库

在 `questions.js` 中：

1. 修改或增加 `dimensions` 条目，填写名称、简介和三档解读。
2. 修改 `questions` 中的题目和选项。
3. 每个选项用 `option("选项文字", "维度id")` 定义。

如果题目总数改变，请同步检查结果页是否至少有三个维度，并重新平衡各维度出现次数。正式上线前，建议请目标用户试答，检查题意是否清楚、选项是否真的可区分，以及报告语言是否让人感到被尊重。

## 使用边界

这是一个自我探索产品原型，不是经过信度与效度检验的心理量表。如果用于正式公开发布，应明确说明非诊断性质，避免恐吓式、绝对化或暗示心理疾病的措辞，也应遵守发布平台的支付与隐私规则。
